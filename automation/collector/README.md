# 매물 자동수집기 기초

목표 흐름:

1. 플랫폼별 수집기(adapter)에서 원본 매물 수집
2. 공통 스키마로 정규화
3. `source + source_listing_id` 기준 1차 중복 판별
4. 주소·가격·면적·유형 조합으로 2차 유사중복 판별
5. 검토대기 큐에 저장
6. 승인된 매물만 홈페이지 `properties` 테이블에 등록

초기 원칙:
- 수집과 홈페이지 공개를 분리한다.
- 신규매물은 자동 공개하지 않고 검토대기 상태를 거친다.
- 원본 출처와 원본 매물번호를 항상 보존한다.
- 확인되지 않은 정보는 임의 생성하지 않는다.
- 플랫폼별 로그인/브라우저 자동화는 adapter 내부로 격리한다.

예정 adapter:
- Naver Real Estate
- 부동산뱅크
- 한방

현재 단계에서는 실제 크롤링 로직보다 공통 데이터 구조와 중복판별/저장 흐름을 먼저 고정한다.
