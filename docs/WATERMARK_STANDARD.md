# 백조현대부동산 매물사진 워터마크 고정 기준

이 문서는 홈페이지 매물사진 워터마크의 단일 기준입니다. 임의 변경 금지.

## 적용 원칙
- 워터마크는 화면 위에 별도 오버레이로 덧씌우지 않는다.
- 원본 사진 파일에 워터마크를 1회만 합성한 뒤 업로드한다.
- 이미 예전 워터마크가 박힌 사진에 새 워터마크를 추가로 겹치지 않는다.
- 기존 사진을 새 기준으로 교체할 때는 반드시 워터마크가 없는 원본 사진을 다시 가져와 새 기준으로 재처리한다.
- 원본이 없는 경우 기존 워터마크가 박힌 사진에서 워터마크만 제거해 복원했다고 간주하지 않는다.

## 고정 자산
- 중앙 워터마크: /public/watermarks/baekjo-watermark-center.webp
- 우측 하단 워터마크: /public/watermarks/baekjo-watermark-corner.webp

## 고정 배치 기준
- 중앙 폭: 사진 폭의 52%
- 중앙 투명도: 0.38
- 중앙 기준 Y: 사진 높이의 60%
- 중앙 최대 높이: 사진 높이의 58%
- 우측 하단 폭: 사진 폭의 27%
- 우측 하단 투명도: 1.0
- 우측 여백: 30px
- 하단 여백: 30px
- 우측 하단 최대 높이: 사진 높이의 34%
- 워터마크는 사진 바깥으로 잘리지 않도록 가로/세로를 동시에 제한한다.

## 출력 기준
- 긴 변 최대 1800px
- JPEG 품질 0.90
- EXIF 방향 보정 후 처리

## 코드 기준
실제 업로드 합성 기준은 `lib/property-images.ts`와 반드시 일치해야 한다.
화면 전역 오버레이 컴포넌트로 매물사진에 워터마크를 추가하지 않는다.

## 기존 등록 사진 교체 절차
1. 워터마크 없는 원본 확보
2. 예전 워터마크가 박힌 저장본은 교체 대상에서 제외
3. 새 기준으로 중앙 + 우측 하단 워터마크 1회 합성
4. 새 파일로 기존 property_images를 교체
5. 홈페이지에서 중복 워터마크가 없는지 확인
